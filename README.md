# Spurghi Reggio Emilia

Next.js 14 App Router + TypeScript site with Tailwind CSS, shadcn/ui-style components, GSAP/ScrollTrigger/SplitText, Lenis and lucide-react.

## Run

```bash
npm install
npm run dev
```

## Hero video

The homepage already renders a muted looping `<video>` background with a black-and-white poster and cinematic fallback overlay.

Place the production video at:

```text
public/video/hero.mp4
```

The rest of the visual system, B/W images and OG image are already present under `public/images`.
